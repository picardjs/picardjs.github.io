Samples ​

The samples repository shows Picard.js in all kinds of applications: single-page apps, server-side rendering with streaming, static site generators, backends written in other languages, desktop and mobile apps, a browser extension, and unit tests. Every sample has a README explaining what Picard.js does there and exactly where it is integrated.

TIP

Looking for a starting point? Pick the sample closest to your stack, then read the matching integration guide: Single-Page Apps, Server-Side Rendering, Desktop & Mobile Apps, or Testing.

The Demo Micro Frontends ​

All samples use the picard-demos feed (https://feed.piral.cloud/api/v1/microfrontends/picard-demos). Its micro frontends are framework-less on purpose, and each one uses a different format:

Micro frontendFormatComponentRendering
mf-simple-htmlModule Federationcolumnclient only
nfsimplehtmlNative Federationcolumnclient only
pi-simple-htmlPiletcounterclient only
pi-ssr-htmlPiletssr-counterserver and client (hydrated)
nf-ssr-htmlNative Federationssr-likesserver and client (hydrated)

The sources of the two server-renderable micro frontends are part of the samples repository. They're a compact reference for writing a component lifecycle that supports stringify, hydration, and update.

The repository also contains picard-decorator, a small Node.js tool that renders micro frontends into HTML produced by something other than a Node.js server. It runs as an HTTP service or as a build step.

Examples in the Picard.js Repository ​

The Picard.js repository has more examples, which focus on individual features rather than on frameworks:

  • static pages, with a feed, with slots, and with routing
  • single-spa components and dependency sharing across formats
  • server-side rendering, islands, and slot / component capabilities
